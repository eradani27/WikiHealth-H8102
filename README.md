
# WikiHealth

WikiHealth adalah website ensiklopedia kesehatan yang menyediakan informasi kesehatan dalam bentuk artikel yang dikelompokkan berdasarkan kategori.

## Fitur

- Menampilkan daftar artikel kesehatan
- Mencari artikel berdasarkan kata kunci
- Memfilter artikel berdasarkan kategori
- Melihat detail artikel
- Menambahkan artikel baru
- Mengedit artikel
- Menghapus artikel

## Teknologi

- HTML
- CSS
- JavaScript

## Cara Menjalankan

1. Clone repository ini:

   ```bash
   git clone https://github.com/eradani27/WikiHealth-H8102.git
   ```

2. Buka folder proyek di Visual Studio Code.
3. Buka file `index.html` melalui browser atau gunakan ekstensi Live Server.
